The ETDP Engine

Designed for Trade & Vocational Educators

Most TVET lecturers are master tradesmen given little training in Outcomes-Based Education (OBE) curriculum design. ETDP automates administrative preparation so educators can focus entirely on practical mastery.

📋

Curriculum Delineation

Ingest official QCTO curricula and assessment specifications (.pdf). Automatically break them down into Qualification Phases, Subjects (KM & PM), Topics, and exact Assessment Criteria.

📚

OBE Learner Guides & Textbooks

Synthesize publication-grade Learner Guides in Microsoft Word (.docx) with structured outcomes, unit chapters, pedagogical review questions, and technical terminology.

⚖️

Summative Assessments & Memoranda

Generate criterion-mapped exam papers, multiple choice, true/false items, and complete assessor answer keys that satisfy rigorous QCTO moderation standards.

🛠️

Lecturer Toolkits & 13-Period Schedules

Local-First & Air-Gapped Ready

🔍 Crossref Source Discovery

Search real-time academic literature through the official Crossref bibliographic API. Instantly retrieve DOIs, authors, publication years, and journal titles for any highlighted text.

Format and insert APA 7 citations at the document cursor with one click (e.g. (Smith & Khumalo, 2026) or (Department of Higher Education, 2024)).

Zero-Dependency Deployment

Standalone Server & Distribution

ETDP hosts both its ASP.NET Core API and React single-page frontend from a unified server process on port 5299. No Node.js or Vite required at runtime.

1. Launch Standalone Server

Starts the unified server in Production mode and opens the application in your default browser:

launch_server.bat

2. Package for Distribution

Creates a self-contained portable distribution package with an auto-run launcher in distribution\etdp_server\:

publish_distribution.bat

3. Developer Mode

Launches backend and Vite frontend with hot-reload for active feature engineering:

launch_etdp.bat
