End-to-End Workflow

Engineered for Vocational & Occupational Training

ETDP bridges the gap between formal South African occupational qualifications and day-to-day classroom delivery with automated, audit-ready educational resources.

📋

Curriculum Alignment

Ingest Quality Council curriculum specifications. Structure qualifications by phases, subjects (Knowledge & Practical modules), topics, and exact assessment criteria.

📚

Automated Courseware

Synthesize publication-grade Learner Guides and Student Workbooks in Microsoft Word (.docx) with formal typographic styling, tables of contents, and illustrative diagrams.

⚖️

Summative Assessments & Memoranda

Generate criterion-mapped exam papers, multiple choice, true/false items, and complete assessor answer keys that satisfy rigorous QCTO moderation standards.

🛠️

Lecturer Toolkit & Schedules

Calculate notional hours, period allocations, and 13-period daily timetables (08:00–16:10). Automate complete lesson plan notes (LPN) for faculty.

🎬

Text-to-Video Educational Studio

Transform curriculum lesson points into animated slide storyboards with instant, client-side virtual frame compilation into downloadable .webm video lectures.

🔒

Local-First & Air-Gapped Ready

Runs completely offline with local SQLite database and local Gemma 4:26B LLM, or in hybrid mode with Google Gemini. No external cloud dependencies required.

Zero-Dependency Deployment

Standalone Server & Distribution

ETDP hosts both its ASP.NET Core API and React single-page frontend from a unified server process on port 5299. No Node.js or Vite required at runtime.

1. Launch Standalone Server

Starts the unified server in Production mode and opens the application in your default browser:

launch_server.bat

2. Package for Distribution

Builds the web bundle and creates a self-contained portable package with an auto-run launcher in distribution\etdp_server\:

publish_distribution.bat

3. Developer Mode

Launches backend and Vite frontend with hot-reload for active feature engineering:

launch_etdp.bat
